HIDAYA AI — Mosque Display

Set this screen up once, then leave it running on your mosque's TV.

1Prayer times

Export "Share Full Year Timetable" from the Hidaya AI phone app, then upload that file here.

OR — no timetable file?

Calculate prayer times automatically instead. A mosque's own timetable (above) should still be preferred when available, since local committee conventions can differ slightly from pure calculation.

2Mosque name & logo

Shown next to the mosque name instead of the default icon.

3Donation details (optional)

Shown scrolling at the bottom of the display so visitors can support the mosque.

4Announcement (optional)
5Display language

Changes the labels shown on screen (Next Prayer, Ayah of the Day, etc.) for visitors — prayer names stay as-is in every language.

6Outdoor weather card (optional)

Shows current outdoor temperature. Needs internet on the display device to update — no browser can read an indoor/room temperature, only real weather data from outside. Leave unset to skip this card.

7Display theme

📺Setting this up ON the TV is hard?

Fill in everything above right here on this phone/computer — much easier than a TV remote (camera for the file, working GPS, a real keyboard). Then get one short link that only needs to be typed ONCE on the TV's browser — it loads this entire setup automatically.

📡No internet on the display itself?

Download one self-contained file (works with an internet connection anywhere — a phone, a café — right now), then copy it to a USB drive and open it on the display device. No internet needed there ever again.
